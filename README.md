# Armario de casa

Gestor del inventario de ropa por contenedores (fotos en Google Drive, listado en Google Sheets, bot de Telegram).

Ábrelo en el móvil con Chrome y pulsa **Instalar app**. La primera vez pide la clave de acceso del gestor
(se crea con la función `crearClaveWeb` del proyecto de Apps Script). La clave no está en este repositorio.
